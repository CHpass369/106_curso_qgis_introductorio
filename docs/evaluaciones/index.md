# Evaluaciones

La evaluación del curso combina **autoevaluación frecuente** (para aprender) con **productos de módulo** (para demostrar lo aprendido). Los pesos están en el [Syllabus](../syllabus.md#evaluacion).

| Componente | Dónde | Peso |
|---|---|---|
| Autoevaluaciones y cuestionarios de módulo | «Comprueba lo aprendido» de cada lección y los cuestionarios de abajo | 15 % |
| Retos de las lecciones | «Inténtalo tú» + criterios de «¿Lo hiciste bien?» | 25 % |
| Productos de módulo | [Práctica M1](../modulo-01/practica.md) · [Taller 2.12](../modulo-02/12-taller-proyecto.md) · [Laboratorio 3.12](../modulo-03/12-laboratorio-decision-territorial.md) | 35 % |
| Producto final | [Taller editorial 4.12](../modulo-04/12-taller-editorial-publicar-coleccion-coherente.md) | 25 % |

## Cuestionarios por módulo

Diez preguntas por módulo, con respuesta desplegable. Incluyen preguntas de **repaso** de módulos anteriores: volver a recuperar lo aprendido semanas después es una de las técnicas de estudio con más respaldo empírico (Dunlosky et al., 2013). Intenta responder **antes** de abrir cada respuesta y apunta tu puntaje: el objetivo es **8 de 10** antes de avanzar.

## Rúbrica común de productos

Se aplica a los productos de módulo, junto con los criterios específicos de cada taller.

| Criterio | 4 · Excelente | 3 · Bueno | 2 · Suficiente | 0 · Insuficiente |
|---|---|---|---|---|
| **Pregunta y propósito** | La pregunta guía todas las decisiones | Clara, con alguna decisión no justificada | Implícita | Ausente |
| **Datos y calidad** | Fuentes, fechas, SRC y limitaciones documentadas | Falta un elemento | Parcial | Sin documentar |
| **Corrección técnica** | Sin errores; cifras de control coinciden | Errores menores que no cambian conclusiones | Errores que matizan conclusiones | Errores que invalidan el resultado |
| **Reproducibilidad** | Otra persona puede rehacerlo (rutas relativas, expresiones, modelos) | Pequeños pasos sin documentar | Difícil de reproducir | Imposible |
| **Comunicación** | Mapas y textos claros para su destinatario | Comprensibles | Requieren explicación | Confusos |
| **Honestidad** | Supuestos y sensibilidad explícitos | Mencionados | Implícitos | Ocultos |

**Aprobación de cada producto:** 14 de 24 puntos y ningún criterio en 0.

## Pauta de crítica de mapas (entre pares)

Usa esta pauta para revisar el mapa de un compañero en 10 minutos. Primero, la **prueba de los 30 segundos**: mira el mapa medio minuto, tápalo y escribe qué entendiste. Luego:

| Pregunta | Sí / No | Comentario |
|---|---|---|
| ¿El mensaje que entendí coincide con el del título? | | |
| ¿Se distingue la figura del fondo sin esfuerzo? | | |
| ¿La representación corresponde al tipo de dato (sin coropletas de totales)? | | |
| ¿La clasificación y la paleta son honestas y legibles en gris? | | |
| ¿La leyenda usa lenguaje claro y unidades? | | |
| ¿Hay escala, fuente, fecha y SRC? | | |
| ¿Alguna etiqueta tapa algo importante o falta? | | |
| ¿Qué **una** cosa cambiarías primero? | | |

La crítica describe el **mapa**, no a la persona, y termina siempre con una propuesta concreta.
