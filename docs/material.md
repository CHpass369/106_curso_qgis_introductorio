# Material de apoyo

Recursos seleccionados para profundizar. Todos son gratuitos salvo que se indique lo contrario.

## Software

| Recurso | Para qué | Enlace |
|---|---|---|
| QGIS | SIG de escritorio usado en el curso | <https://qgis.org/download/> |
| QField | Captura de datos en campo con proyectos QGIS | <https://qfield.org> |
| ColorBrewer 2.0 | Elegir paletas para mapas temáticos | <https://colorbrewer2.org> |
| epsg.io | Buscar y comparar sistemas de referencia | <https://epsg.io> |
| Viz Palette | Simular daltonismo en paletas | <https://projects.susielu.com/viz-palette> |

## Datos abiertos para Bolivia

| Fuente | Contenido | Enlace |
|---|---|---|
| GeoBolivia (IDE del Estado Plurinacional) | Límites, catastro, temáticos oficiales | <https://geo.gob.bo> |
| Instituto Nacional de Estadística (INE) | Censos, cartografía estadística | <https://www.ine.gob.bo> |
| Instituto Geográfico Militar (IGM) | Red geodésica MARGEN-SIRGAS, cartografía base | <https://www.igmbolivia.gob.bo> |
| OpenStreetMap | Vías, equipamientos, edificaciones | <https://www.openstreetmap.org> |
| Copernicus DEM GLO-30 | Modelo digital de elevación de 30 m | <https://dataspace.copernicus.eu> |
| Copernicus Sentinel-2 | Imágenes multiespectrales de 10 m | <https://dataspace.copernicus.eu> |
| Natural Earth | Cartografía de contexto a pequeña escala | <https://www.naturalearthdata.com> |

## Libros y cursos libres

- Olaya, V. *Sistemas de Información Geográfica*. Libro libre en español. <https://volaya.github.io/libro-sig/>
- QGIS Project. *Una introducción amable a los SIG*. <https://docs.qgis.org/latest/es/docs/gentle_gis_introduction/>
- QGIS Project. *Manual de entrenamiento de QGIS*. <https://docs.qgis.org/latest/es/docs/training_manual/>
- Gandhi, U. *Spatial Thoughts* — cursos gratuitos de QGIS (en inglés). <https://courses.spatialthoughts.com>
- ITC, Universidad de Twente. *Principles and Applications of GIS and Earth Observation* — ejercicios con QGIS. <https://principles-and-applications-of-rs-and-gis.readthedocs.io>
- Penn State. *GEOG 486 · Cartography and Visualization*. <https://courses.ems.psu.edu/geog486/>
